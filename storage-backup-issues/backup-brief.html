Our office file backup: where we stand

The office file server copies about 50 GB of staff work to Microsoft Azure every day. This page covers what that setup protects, where it falls short, what we can fix for free, and what still needs budget.

How it works today

Data is encrypted in transit and in storage, and nobody can get in without a password key. Three gaps remain.

Today The problems

  • The cloud copy is a mirror, not a backupIf ransomware scrambles files or someone deletes a folder, the change copies to Azure within minutes. Both copies are then damaged.
  • Veeam backups sit in the same buildingA fire, theft or ransomware attack on the office could destroy the files and their backups at the same time.
  • Cloud storage accepts connections from anywhereA leaked or stolen access key would work from any computer in the world.

Free fixes What IT will do now

  • Only accept connections from our officeLock Azure storage to the office's fixed internet address. A stolen key becomes useless from anywhere else.
  • Change the access keysReplace the existing keys in case an old copy is lying around.

After the fixes Risks that remain

  • Still no ransomware-proof copyThe free fixes don't stop damaged files from syncing over the good cloud copy. We need dated daily snapshots we can roll back to.
  • Cloud storage still has a public entranceThe entrance is locked to our office, but it's still visible on the internet. Upcoming compliance audits may ask for a fully private connection.
  • Veeam backups can be attackedWithout a tamper-proof (immutable) store, ransomware can delete the backups too.

What we're asking for, in priority order

1. Azure Backup for our file share

Daily dated snapshots kept for 30 days or more. This closes the biggest gap. At our size the cost is low, estimated in the tens of dollars per month.

2. Later, for compliance: private connection

A VPN link to Azure with a private endpoint, which removes the public entrance. Expect roughly $150–350 per month, and plan it when compliance work starts.
